# Status — random-play

## What works now
- Static landing page with 5 categories + "All".
- Random pick from selected category, shown before opening (no surprise redirect).
- Open in new tab, Copy link, Roll again.
- `links.json` config; built-in fallback if it fails to load.

## Next steps
- Optional "history of recent picks".
- Weighting / "don't repeat last N".
- A small admin form to add links without editing JSON by hand.
- Per-category cover colours or icons.
